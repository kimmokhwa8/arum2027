# 🏫 우리 반 교실

화면 공유, 프롬프트 복사, 자료 게시판을 한 사이트에 모은 수업용 웹앱이에요.
학교 PC 크롬이나 엣지에서 쓰고, 학생 15명 정도까지 쓰도록 맞춰 두었어요.

| 탭 | 선생님 | 학생 |
|---|---|---|
| 📺 화면 공유 | 학생 화면 모아 보기(전체/4분할/1명씩), 한 명 눌러 크게 보기, 이름순·들어온 순 정렬, 🔗 링크 한 번에 보내기, 전체 종료 | 코드와 이름으로 입장 → [화면 공유 시작], 공유 중에는 "선생님이 보고 있어요"가 항상 보임 |
| 📋 프롬프트 | 프롬프트 추가, 수정, 삭제, 순서 바꾸기 (바로 학생 화면에 반영) | 큰 [복사] 버튼 → Ctrl+V로 붙여 넣기 |
| 📁 게시판 | 자료 올리기, 아무 글이나 지우기, 전체 지우기 | 글, 사진, 파일(10MB까지) 올리기, 내 글 지우기 |

---

## 1. 인터넷에 올리기 (처음 한 번만, 약 15분)

사이트를 인터넷 주소로 만들어 주는 무료 서비스 **Render**를 써요.
코드를 올려 둘 곳으로 **GitHub**도 필요해요. 둘 다 무료 가입이에요.

### ① GitHub에 파일 올리기
1. https://github.com 에 가입하고 로그인해요.
2. 오른쪽 위 **[+] → New repository**를 눌러요.
3. Repository name에 `arum-classroom`처럼 이름을 쓰고 **Public**을 고른 뒤 **Create repository**를 눌러요.
4. 다음 화면에서 **uploading an existing file** 글자를 눌러요.
5. 압축을 푼 `classroom` 폴더 **안의 파일과 폴더 전부**(`server.js`, `package.json`, `public` 폴더 등)를 끌어다 놓아요.
6. 아래쪽 **Commit changes**를 눌러요.

### ② Render에서 사이트 만들기
1. https://render.com 에서 **GitHub 계정으로 가입**해요.
2. **New + → Web Service**를 눌러요.
3. 방금 만든 `arum-classroom` 저장소를 고르고 **Connect**를 눌러요.
4. 아래처럼 칸을 채워요.
   - **Language**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: **Free**
5. **Deploy Web Service**를 누르고 2~3분 기다려요.
6. 위쪽에 `https://arum-classroom-xxxx.onrender.com` 같은 주소가 생기면 끝이에요!

> 주소가 `https://`로 시작해야 화면 공유가 돼요. Render 주소는 자동으로 https예요.

## 2. 수업에서 쓰기

**선생님**
1. 수업 **5분 전**에 `내주소/teacher.html`을 열어요. (무료 서버는 쉬고 있다가 깨어나는 데 1분쯤 걸려요)
2. 교실 코드 6자리가 나와요. **[코드 크게 보기]**로 전자칠판에 띄워 주세요.
   같은 컴퓨터에서 다시 열면 **같은 코드**가 나와서 한 학기 내내 쓸 수 있어요.

**학생**
1. `내주소/student.html`에 들어가요.
   (북마크해 두거나, 바탕화면 바로가기를 만들어 두면 편해요)
2. 교실 코드와 이름을 넣고 **[들어가기]**를 눌러요. "이 컴퓨터에 저장하기"를 켜 두면 다음부터는 버튼만 누르면 돼요.
3. **[화면 공유 시작] → '전체 화면' → 화면 그림 클릭 → [공유]**를 눌러요.
4. 이 창은 그대로 두고, 다른 창이나 탭에서 활동하면 돼요.

## 3. 꼭 알아 두세요

- **무료 서버는 15분 동안 아무도 안 쓰면 잠들어요.** 잠들면 서버에 있던 **게시판 글과 파일이 지워질 수 있어요.**
  - 교실 코드와 **프롬프트는 선생님 컴퓨터에 백업**해 두었다가 자동으로 되살려요.
  - 게시판은 **그날 수업용**으로 생각하고, 남겨야 할 결과물은 수업이 끝나기 전에 내려받아 두세요.
  - 게시판을 오래 보관하려면 Render 유료 디스크를 붙이거나(월 몇 달러), 저장소를 따로 연결하면 돼요.
- **화면은 녹화나 저장을 하지 않아요.** 학생 PC에서 선생님 PC로 바로 전달돼요.
- 학교 보안 프로그램이나 방화벽 때문에 **화면이 "연결하는 중…"에서 멈추면** 학교 전산 담당 선생님께 WebRTC(화상 연결) 허용을 문의해 주세요.
  그래도 안 되면 `public/common.js`의 `RTC_CONFIG`에 TURN 서버를 추가하면 돼요.
- 휴대폰과 태블릿에서는 화면 공유가 되지 않아요. (프롬프트와 게시판 탭은 돼요)
- 학생 화면을 보는 도구이니, 처음 쓰기 전에 **학생과 보호자에게 미리 안내**해 주세요.

## 4. 고치고 싶을 때

| 바꾸고 싶은 것 | 파일 |
|---|---|
| 글자, 색, 크기 | `public/style.css` |
| 학생 화면 문구 | `public/student.html` |
| 선생님 화면 | `public/teacher.html` |
| 파일 용량 제한(10MB) | `server.js`의 `MAX_FILE_MB` |

GitHub에서 파일을 고치고 저장(Commit)하면 Render가 몇 분 뒤 자동으로 새로 올려요.

내 컴퓨터에서 시험해 보려면 Node.js를 설치한 뒤 이 폴더에서 `npm install` → `npm start`를 하고 `http://localhost:3000`을 열어요.
